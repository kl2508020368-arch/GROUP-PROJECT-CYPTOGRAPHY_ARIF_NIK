# Stream Cipher Project

## Description

This project implements a simplified RC4-based stream cipher using Python.

## Components

- Key Scheduling Algorithm (KSA)
- Pseudo-Random Generation Algorithm (PRGA)
- XOR encryption and decryption
- Performance testing

## Files

- `stream_cipher.py` - Stream cipher implementation
- `benchmark_stream.py` - Performance testing for different file sizes

## Test Sizes

The performance test uses:

- 1 KB
- 100 KB
- 1 MB

## How to Run

Run the stream cipher:

```bash
python stream_cipher.py
